<p>İnce inşaat ve iç mekan bitirme işlerinde en sık karşılaşılan hatalardan biri, boya seçiminin yalnızca renk ve marka üzerinden yapılmasıdır. Oysa yapı fiziği ve malzeme mühendisliği açısından uzun ömürlü, çatlamayan, kabarıklaşmayan ve silinebilir bir iç cephe kaplaması elde etmenin sırrı: <strong>Doğru Yüzey Hazırlığı + Doğru Astar (Primer) + Doğru Boya Türü</strong> üçlüsünün mükemmel uyumudur.</p>

<p>Bu teknik rehberde; brüt betondan alçı sıpaya, alçıpandan eski boyalı yüzeylere kadar farklı alt katmanlarda uygulanması gereken astar türlerini, boya kimyasını ve şantiye sarfiyat hesaplama yöntemlerini inceliyoruz.</p>

<h4 style="color: var(--text-primary); margin-top: 2.5rem; margin-bottom: 1rem;">1. İç Cephe Yüzey Türleri ve Astar (Primer) Gereksinimleri</h4>

<p>Astar, boyanın alt yüzeye tutunmasını (aderans) sağlayan, yüzey emiciliğini dengeleyen ve boya sarfiyatını %25-%40 oranında azaltan hayati bir bağlayıcı katmandır. Yüzey türüne göre astar seçimi şu şekilde yapılmalıdır:</p>

<ul>
    <li><strong>Alçı Sıva ve Saten Alçı Yüzeyler:</strong> Yüksek derecede emici ve tozuyabilir karakterdedir. Bu yüzeylerde ham boya direkt uygulanırsa boyanın suyu emilir, boya bağlayıcısını kaybeder ve pul pul dökülür. Buradaki ideal çözüm <em>Şeffaf Penetrasyon Astarı (Binder)</em> veya <em>Alçı Astarı</em> uygulamasıdır.</li>
    <li><strong>Brüt Beton ve Pürüzsüz Kalıp Yüzeyleri:</strong> Emiciliği son derece düşük, yüzeyi cam gibi pürüzsüzdür. Standart astarlar tutunamayacağı için mekanik kilitlenme sağlayan <em>Kuvars Kumu Katkılı Brüt Beton Astarı</em> kullanılmalıdır.</li>
    <li><strong>Alçı Levha / Alçıpan (Drywall):</strong> Derz dolgusu yapılan yerler ile alçıpan kağıdı arasında emicilik farkı oluşur. Renk ve emicilik dalgalanmasını önlemek için <em>Örtücü (Dönüşüm / Şeffaf Olmayan) İç Cephe Astarı</em> uygulanmalıdır.</li>
    <li><strong>Eski Boyalı ve Renk Değişimli Yüzeyler:</strong> Koyu renkten açık renge geçişlerde veya sentetik (solvent bazlı) boyadan su bazlı boyaya dönüşümde <em>Geçiş Astarı (Dönüşüm Astarı)</em> ile mikro-tutunma yüzeyi oluşturulmalıdır.</li>
</ul>

<h4 style="color: var(--text-primary); margin-top: 2.5rem; margin-bottom: 1rem;">3. Şantiye Hesabı: Boya ve Astar Sarfiyatı Nasıl Hesaplanır?</h4>

<p>İç cephe boya hesabında teorik sarfiyat değerleri üzerinden net alan hesabı yapılır. Standart bir konut odasında süpürgelik ve kapı-pencere düşümleri sonrası net duvar alanı belirlenir:</p>

<p>$$\text{Net Duvar Alanı (m²)} = \text{Çevre (m)} \times \text{Yükseklik (m)} - \text{Kapı/Pencere Alanları (m²)}$$</p>

<p>Genel malzeme sarfiyat katsayıları:</p>
<ul>
    <li><strong>İç Cephe Astarı Sarfiyatı:</strong> Tek katta 1 Litre Astar ile yaklaşık <strong>12 - 15 m²</strong> alan kaplanır.</li>
    <li><strong>İç Cephe Boyası Sarfiyatı (Çift Kat):</strong> Çift kat uygulamada 1 Litre Boya ile yaklaşık <strong>6 - 8 m²</strong> net alan kaplanır (1 kg boya $\approx$ 6.5 m² çift kat).</li>
    <li><strong>Tavan Boyası Sarfiyatı (Çift Kat):</strong> 1 Litre tavan boyası ile çift katta yaklaşık <strong>5 - 7 m²</strong> tavan alanı boyanır.</li>
</ul>

(function() {
    function calcPaintRequirements() {
        const len = parseFloat(document.getElementById('inpPaintRoomLen')?.value || '6.0');
        const wid = parseFloat(document.getElementById('inpPaintRoomWidth')?.value || '4.0');
        const hght = parseFloat(document.getElementById('inpPaintRoomHeight')?.value || '2.8');
        const open = parseFloat(document.getElementById('inpPaintOpenings')?.value || '6.0');
        const stype = document.getElementById('inpPaintSurfaceType')?.value || 'alci';
        const coats = parseInt(document.getElementById('inpPaintCoats')?.value || '2');

        const grossWallArea = 2 * (len + wid) * hght;
        const netWallArea = Math.max(5, grossWallArea - open);
        const ceilingArea = len * wid;

        // Primer calculation
        let primerCoverageM2Ltr = 12;
        if (stype === 'alci') primerCoverageM2Ltr = 10; // alci absorbs more
        else if (stype === 'brut') primerCoverageM2Ltr = 8; // quartz primer heavier
        else if (stype === 'eski') primerCoverageM2Ltr = 14;

        const primerLtr = netWallArea / primerCoverageM2Ltr;

        // Paint calculation (double coat baseline: 7 m² / Ltr)
        let paintCoverageM2LtrPerCoat = 14;
        const paintLtr = (netWallArea * coats) / paintCoverageM2LtrPerCoat;

        // Ceiling paint calculation (2 coats baseline)
        const ceilingLtr = (ceilingArea * 2) / 13;

        // Packaging helpers
        const getBucketText = (ltr) => {
            if (ltr <= 2.5) return `${ltr.toFixed(1)} Lt (2.5L Ambalaj)`;
            if (ltr <= 7.5) return `${ltr.toFixed(1)} Lt (7.5L Kova)`;
            if (ltr <= 15) return `${ltr.toFixed(1)} Lt (15L Kova)`;
            const buckets = Math.ceil(ltr / 15);
            return `${ltr.toFixed(1)} Lt (${buckets} Adet 15L Kova)`;
        };

        const setVal = (id, val) => {
            const el = document.getElementById(id);
            if (el) el.innerText = val;
        };

        setVal('outNetWallArea', `${netWallArea.toFixed(1)} m²`);
        setVal('outCeilingArea', `${ceilingArea.toFixed(1)} m²`);
        setVal('outPrimerLtr', getBucketText(primerLtr));
        setVal('outPaintLtr', getBucketText(paintLtr));
        setVal('outCeilingLtr', getBucketText(ceilingLtr));
    }

    ['inpPaintRoomLen', 'inpPaintRoomWidth', 'inpPaintRoomHeight', 'inpPaintOpenings', 'inpPaintSurfaceType', 'inpPaintCoats'].forEach(id => {
        const el = document.getElementById(id);
        if (el) {
            el.addEventListener('input', calcPaintRequirements);
            el.addEventListener('change', calcPaintRequirements);
        }
    });

    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', calcPaintRequirements);
    } else {
        calcPaintRequirements();
    }
})();
</script>

<h4 style="color: var(--text-primary); margin-top: 2.5rem; margin-bottom: 1rem;">4. Şantiyede Kaliteli Uygulama İçin Altın Kurallar</h4>

<ul>
    <li><strong>Sıcaklık ve Nem Kontrolü:</strong> Uygulama sırasında ortam sıcaklığı <strong>+5°C ile +35°C</strong> arasında olmalı, yüzey nemi %10'un altında bulunmalıdır. Şantiyede rüzgarlı ve aşırı sıcak havalarda hızlı kuruma nedeniyle rulo izleri oluşabilir.</li>
    <li><strong>Katlar Arası Kuruma Süresi:</strong> Astar uygulamasından sonra en az <strong>4-6 saat</strong>, boya katları arasında ise en az <strong>6 saat</strong> beklenmelidir. Tam mekanik sertleşme ve silinebilirlik direnci 7-14 günde kazanılır.</li>
    <li><strong>Rulo ve Fırça Seçimi:</strong> Saten alçı ve düzgün yüzeylerde <em>Kadife (Kısa Havlı) Rulo</em>, pürüzlü veya grenli yüzeylerde <em>Uzun Havlı İplik Rulo</em> tercih edilmelidir. Kestirme işlerinde sentetik kıllı fırçalar iz bırakmaz.</li>
</ul>
